**Справка по работе с документами ЛСО** и учебные заведения с кодами специальностей — в базе проверки анкет.

## Что нового

- **Справка** (меню → «Справка: документы ЛСО», ссылка внизу страницы и карточка на главной) — методическое пособие
  ХРО МООО «РСО» по работе с документами ЛСО:
  - оформление кандидата в члены ХРО МООО «РСО» по шагам: сроки, цели, задачи;
  - пакет документов кандидата — у каждого документа кнопка «Образец»: образцы заполнения заявлений и учетной карточки,
    примеры сканов паспорта, ИНН, СНИЛС, полиса ОМС, справки с места учебы, приписного удостоверения (открываются крупно);
  - как разложить документы, цвета папок со сканами, как назвать папку и сканы;
  - **названия для кандидата**: введите ФИО — готовые названия папки, сканов и учетной карточки, каждое можно скопировать;
  - учетная карточка: формат, шрифт, сетка, почта мастера ХРО МООО «РСО» (с копированием);
  - лист «Кандидаты» в журнале учета и как проверить его в «Проверке анкет»;
  - работа в журнале учета членов ЛСО (раздел в пособии пока дополняется);
  - **приложения 1–5** — учебные заведения Абакана, Красноярска, Минусинска, Саяногорска и Черногорска с кодами
    специальностей: поиск по названию и коду, фильтр по городу, копирование сокращённого наименования и направления.
- **«Учебные заведения из справки» в базе** («База данных»): одной кнопкой все учебные заведения и направления
  (или одного города) попадают в древо «Место учебы» — и такие значения в анкетах проходят проверку без подтверждения.
  Повторное добавление ничего не дублирует. В «Предложения в базу» эти значения не уходят.
- **«Направление обучения»** по умолчанию:
  - сверяется со списком своего места учебы (настройка «Своё для каждого места учебы» — можно выключить);
  - принимает код профессии из 5 цифр — «19601 Швея» (настройка «Код профессии из 5 цифр»).
- Поле поиска на странице «База данных» больше не растягивается по высоте.
- Частые вопросы: как оформить кандидата, откуда взять учебные заведения и коды специальностей.

## Данные

Направления обучения, подтверждённые раньше, лежат в древе «Направление обучения (с кодом специальности)»: с новой
проверкой по умолчанию они не используются (направления теперь хранятся внутри места учебы). Вернуть прежнее поведение —
выключить «Своё для каждого места учебы» в настройках столбца. Остальные данные сохраняются.
