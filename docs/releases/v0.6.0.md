**Генератор документов: учётная карточка члена организации.** Второе приложение — документы Word из базы людей.

## Что нового

- **«Генератор документов»** открыт (раньше был «Скоро»). Первый документ — **учётная карточка члена организации**
  (бланк с 01.01.2026), заполняется по образцу из методического пособия по работе с документами ЛСО.
- **Данные — из базы людей.** В списке видно, у кого сколько данных не хватает; человека можно ввести и вручную.
- **Недостающее — там же.** Пустые поля подсвечены, к каждому — подсказка и образец из методички. Вписанное можно
  **дописать в базу людей** одной кнопкой: недостающее отмечено сразу, изменённое — по выбору.
- **Как в образце:** Times New Roman 12, сетка таблицы не меняется, длинный адрес продолжается на следующей строке
  карточки, файл называется «Фамилия И.О. - Учетная карточка члена организации».
- **«Информ. рассылка» — галочка-символ** вместо квадрата (✓ или ☑, как в образце; без согласия — ☐).
- **Подсказки к формату:** даты, серия и номер паспорта, телефон «8(923)123-45-67», индекс в адресе — с кнопкой
  исправления. Место учёбы — сокращённое название из приложений методички (полное сокращается по кнопке, есть список).
- **Предпросмотр бланка** с теми же пропорциями: видно, что куда попадёт и что не помещается; нажатие — переход к полю.

## Данные

- В базе людей появились поля вне анкеты: «Место работы» и «Должность на работе».
- Сохранение анкеты в базу людей больше не стирает поля, которых нет в таблице (их дописало другое приложение).
- Новый файл настроек: `Генератор документов/settings.json`. Готовые карточки — в `Генератор документов/Учетные карточки`.
