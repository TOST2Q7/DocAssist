**Новая механика проверки анкет.** Без сложных алгоритмов: только регулярные выражения, база «ключ:значение» и древо.

## Что изменилось

- **35 столбцов анкеты по порядку**, у каждого своё название, как в форме («Отметка времени», «Регион», «Фамилия»… «Отметка
  проверки перс. данных»). Таблица без строки заголовков понимается по порядку столбцов.
- **Правило у каждого столбца** («Шаблоны и правила»): формат (regex), список из базы или древо с конструктором.
  Готовые форматы: телефон `8(000)000-00-00`, почта, даты, СНИЛС, ИНН, серия и номер паспорта, код подразделения,
  ссылка `https://vk.ru/…` / `https://vk.com/…`. Исправления по маске: «80000000000» → «8(000)000-00-00».
- **Конструктор ячейки** для адресов и места рождения: ячейка дробится по запятым и пробелам, слова классифицируются
  (приписка «Респ.», «р-н», «ул.» / название / цифры). Порядок записи в древо — `2, 1, 3, *`; описания частей можно
  переписать, приписки — как в таблице. Индекс хранится под регионом: тот же индекс или населённый пункт в другом
  регионе — ошибка.
- **База сначала пустая.** Новое значение — предупреждение и «Подтвердить»; «Новые слова» подтверждают всё разом.
  Вкладка «База» и страница «База данных»: просмотр древ, удаление, **ручное добавление** «тег + слово» с предупреждениями
  (не по формату, есть приписка — «сохранится неправильно»).
- **Индивидуальное — всегда с галочкой.** ФИО, дата рождения, паспорт, СНИЛС, ИНН, телефон, почта, ВК, курс, группа
  подтверждаются у каждого человека отдельно. Уникальные значения: повтор у другого человека — ошибка.
- **База людей и «Проверить с актуальной информацией».** Готовые анкеты сохраняются в базу людей; кнопка находит
  человека по ФИО, отмечает совпавшие поля проверенными и перечисляет несовпавшие.
- **Таблица через Ctrl+V** — строки из Excel или Google Таблиц, заголовки не обязательны. На телефоне — «Вставить из буфера».
- **Переменные по Ctrl+Пробел** в любом поле ввода — как подсказки в редакторе кода. Сами по себе не всплывают.

## Перенос данных

Таблицы и правки из 0.2 сохраняются. Настройки правил и прежние справочники не переносятся — новая проверка начинает
с пустой базы; «Принять как есть» заменено галочками подтверждения.
