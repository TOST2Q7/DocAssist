**Строгая проверка анкет.** Система проверки переписана с нуля: шаг влево/вправо — ошибка.

## Что изменилось

- **Вердикт — точное совпадение с шаблоном.** Для каждого поля строится единственно правильная форма. Любое отличие —
  лишнее слово («ул. Ленина Привет»), лишняя точка, двойная запятая, пробел в конце, регистр, порядок, кавычки —
  ошибка с подсветкой места и исправлением. Раньше часть таких огрехов проходила без замечаний.
- **Нет «предупреждений».** Два статуса: «ошибка» и «подтвердить». Анкета готова, только когда нет ни того, ни другого.
- **Неизвестное не проходит молча.** Новые сёла, улицы, индексы, имена, отряды, учебные заведения, подразделения,
  выдающие паспорта, нужно один раз подтвердить — после этого они становятся образцом для всех анкет.
  Кнопка «Новые слова» собирает их по всей таблице.
- **Шаблоны адресов** с обязательными и запрещёнными частями (например, район в адресе регистрации не указывается,
  а в месте рождения — обязателен) и требованиями к справочнику (населённый пункт, улица, индекс).
- **Маски** для телефона и номера членского билета, справочник имён (≈450) с автоматическими отчествами.
- **Новые перекрёстные проверки:** «Кем выдан» ↔ код подразделения, пол ↔ имя и отчество, форма фамилии, курс ↔ уровень
  образования, даты ↔ дата заполнения анкеты.
- **«Принять как есть»** — для значений, которые верны, но не подходят под шаблон. При изменении значения проверка вернётся.

## Перенос данных

Настройки и правки из версии 0.1 переносятся автоматически. «Скрытые предупреждения» из 0.1 сброшены — эти места
нужно проверить заново по строгим правилам.
