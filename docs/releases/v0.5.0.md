**Проверка анкет стала умнее и проще в настройке.**

## Что нового

- **Настройки правил — переключателями и полями.** «Шаблоны и правила» → столбец: сверху настройки, например «Курс от» и
  «Курс до», «Обязательное», «Галочка у каждого человека», список вариантов для «Пола». Рядом — «Проверить значение»:
  впишите значение и сразу увидите результат.
- **Буква «й», записанная двумя символами,** и **латинские буквы в русских словах** («Ивaнов» с латинской «a») — теперь
  ошибка с готовым исправлением.
- **Почта с заглавными буквами** больше не ошибка — только совет исправить на строчные.
- **Новые подсказки:** возраст вне 14–35 лет, неверное контрольное число СНИЛС и ИНН, паспорт выдан раньше 14 лет,
  дата исключения раньше даты вступления. Лишнее можно выключить в настройках столбца.
- **Игнорировать ошибку** — у отдельного замечания, у всей анкеты или у всей таблицы (с подтверждением). Замечание
  остаётся видно зачёркнутым и не мешает готовности; вернуть — той же кнопкой.
- **Копия всех данных в файл.** «Рабочая папка» → «Сохранить копию в файл»: один .zip со всем — таблицы, правки, база,
  настройки. Из него же можно восстановить данные в любом браузере. Особенно важно, если вы работаете в «Хранилище
  браузера».
- **Подсказки у кнопок** больше не уходят за край экрана.
- **«Скопировать настройки»** (временно) — чтобы отправить свои настройки разработчику.

## Для настройщика

Правила столбцов теперь — короткий код (Lua), который можно открыть кнопкой «Код проверки — для настройщика»: окно с
подсказками по Ctrl+Пробел, шаблонами и справкой рядом, ошибки в коде объясняются по-русски. Из кода доступны другие
ячейки анкеты и их галочки «Проверено», база, свои функции и общие проверки для всех ячеек. Всё описано во вкладке
«Справка».

## Данные

Таблицы, правки, галочки, база, база людей, переменные и словарь сохраняются. Настройки правил из прошлых тестовых
версий не переносятся — правила начинаются с настроек по умолчанию.
